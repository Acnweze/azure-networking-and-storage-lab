# Azure Infrastructure Hands-on Lab

##  Overview
This project demonstrates hands-on implementation of Microsoft Azure core services including networking, virtual machines, storage, and security.

The goal was to build, manage, and secure cloud infrastructure using real Azure resources.

---

##  What I Built

###  Networking
- Created a new subnet in an existing Virtual Network (VNet)
- Created and configured a Network Security Group (NSG)
- Associated NSG with a subnet
- Moved a virtual machine to a new subnet

###  Compute
- Vertically scaled a virtual machine (resize)
- Attached data disks to a VM
- Configured automatic shutdown for cost control

###  Storage
- Created a storage account container
- Created an Azure File Share
- Generated Shared Access Signature (SAS) token
- Rotated storage access keys

###  Security & Governance
- Added tags to resources for organization
- Managed resource locks on virtual machines
